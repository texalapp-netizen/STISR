## Introduction

Scene Text Image Super-Resolution (STISR) aims to recover high-resolution and readable text images from low-resolution inputs.  
This repository collects representative STISR papers and organizes them **by academic tiers (Q1/Q2/Q3)** for easier navigation and literature review.
